# Guide de style front-end

## Mise en page

Les designs ont été créés pour les largeurs suivantes :

- Mobile : 375 px
- Ordinateur de bureau : 1 440 px

> 💡 Il s’agit uniquement des dimensions utilisées pour les designs. Assurez-vous que le contenu est responsive (adaptatif) et respecte les exigences WCAG en testant toute la gamme de tailles d’écran, de 320 px jusqu’aux grands écrans.

## Couleurs

- Blanc : `hsl(0, 0%, 100%)`

- Slate 300 : `hsl(212, 45%, 89%)`

- Slate 500 : `hsl(216, 15%, 48%)`

- Slate 900 : `hsl(218, 44%, 22%)`

## Typographie

### Texte du corps

- Taille de police (paragraphe) : 15 px

### Police

- Famille : [Outfit](https://fonts.google.com/specimen/Outfit)
- Épaisseurs : 400, 700

> 💎 Il s’agit d’un challenge « free+ ». Si vous souhaitez voir tous les détails du design et vous entraîner à utiliser des outils professionnels comme Figma, vous pouvez télécharger le fichier de design à partir de l’endroit où vous avez téléchargé le code de départ.
